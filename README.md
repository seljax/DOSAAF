# ДОСААФ — Учебный портал автошколы

Веб-приложение для курсантов и администраторов автошколы ДОСААФ.  
Версия: **v0.04**

---

## 📋 О проекте

Портал предоставляет курсантам доступ к учебным материалам, тестам, расписанию и личному профилю. Администраторы управляют пользователями, контентом и видят журнал действий.

### Основные возможности

**Для курсантов:**
- 📖 Правила дорожного движения и дорожные знаки
- 📝 Тесты и экзамены по категориям
- 📚 Учебные материалы (видео, статьи, руководства)
- 📅 Расписание занятий
- 📊 Статистика прохождения тестов
- 👤 Личный профиль со сменой пароля
- 🔒 Матрица доступа — видно, какие разделы открыты

**Для администраторов:**
- 👥 Управление курсантами (создание, редактирование, блокировка)
- 🔑 Управление доступом курсантов к разделам
- 📝 Редактирование знаков, правил, тестов, материалов
- 📋 Журнал действий (логи) с фильтрацией
- 🎨 Визуальный редактор (Elementor-подобный)
- 🎭 Переключатель темы (светлая / тёмная / фирменная ДОСААФ)
- ⚙️ Настройка вкладок навигации
- 🦶 Редактирование подвала сайта

- **Node.js v22 или выше** (для `node:sqlite`)

```bash

🔌 API
Все эндпоинты находятся на порту 3000 (или того, что указан в server.ts).

Метод	Эндпоинт	Описание
GET	/api/health	Проверка работы сервера
GET	/api/data	Получить все сохранённые данные
POST	/api/data	Сохранить данные (принимает { key, value } или { data: {...} })
Формат ответа GET /api/data
json
{
  "success": true,
  "data": {
    "groups": [...],
    "signs": [...],
    "students": [...],
    "activityLogs": [...],
    "live_app_designs": {...},
    "appTheme": "dark"
  }
}
Формат запроса POST /api/data
Одно значение:

json
{ "key": "appTheme", "value": "dark" }
Несколько значений:

json
{
  "data": {
    "appTheme": "dark",
    "footerSettings": {...}
  }
}
💾 База данных
Файл: dosaaf_data.sqlite (в корне проекта)

Таблица: app_data

Колонка	Тип	Описание
key	TEXT	Уникальный ключ
value	TEXT	Значение (JSON-строка)
updated_at	INTEGER	Время последнего обновления (timestamp)
Ключи, которые хранятся в базе:

groups — группы курсантов

signs — дорожные знаки

rules — правила ПДД

categories, questions — тесты

lessons, schedule, materials — учебные материалы

students — учётные записи курсантов

adminCredentials — логин и пароль администратора

activityLogs — журнал действий

footerSettings, navTabs, siteInfo — настройки интерфейса

appTheme — текущая тема

live_app_designs — настройки визуального редактора

⚠️ База данных НЕ должна попадать в Git (см. .gitignore).
Для бэкапа копируйте файл вручную.
